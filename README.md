# Algorithm for Calculating Fuel Required and Total Fuel Cost for a Road Trip

Algorithm for calculating the fuel required and total fuel cost for a road trip using distance, vehicle mileage, and fuel price.

```
START
READ DISTANCE, MILEAGE, FUEL_PRICE
CALCULATE FUEL_REQUIRED = DISTANCE / MILEAGE
CALCULATE TOTAL_FUEL_COST = FUEL_REQUIRED * FUEL_PRICE
DISPLAY TOTAL_FUEL_COST AND FUEL_REQUIRED
STOP
```
